# 🏴‍☠️ Nightmare CTF

**Nightmare CTF** is a Capture The Flag (CTF) competition authored and organized by me.  
This repository contains the official challenge files, source materials, and intended solutions for the competition.

The challenges are designed to test both technical skills and analytical thinking across multiple cybersecurity domains.

---

## 🎯 About the Competition

Nightmare CTF focuses on:
- Practical security concepts
- Realistic attack scenarios
- Learning-oriented challenges
- Clear difficulty progression

The competition includes challenges suitable for beginners to intermediate players.

---

## 🧩 Categories

| Category | Description |
|--------|------------|
| 🔐 Cryptography | Classical & modern cryptography challenges |
| 🕵️ OSINT | Open-source intelligence challenges |
| 🌐 Web | Web security & logic vulnerabilities |
| 🌍 Network | Network traffic & protocol analysis |
| 🧪 DFIR | Digital forensics & incident response |

---

## 🛠 Challenge Design Philosophy
- Clear and realistic scenarios
- No guess-based challenges
- Educational value over tricking players
- Emphasis on understanding, not brute force

---

## ⚠️ Disclaimer
- This repository is intended for **educational purposes**.
- Flags may be redacted or stored separately.
- Do not deploy challenges without proper isolation and security controls.
